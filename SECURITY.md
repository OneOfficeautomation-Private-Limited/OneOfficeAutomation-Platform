# Security policy

## Reporting a vulnerability

Email **support@oneofficeautomation.com** with "Security" in the subject. Please include the version (the setup or MSI file name), what you did, what happened, and how to reproduce it. Do not include real customer
data or passwords.

We confirm that we received your report, keep you informed while we investigate, and tell you when a fix is released.
Please give us time to release a fix before you publish details.

## Supported versions

The latest release receives security fixes. Customers on an older release are asked to upgrade.
